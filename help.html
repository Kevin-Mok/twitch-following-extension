Find your live follows.

Connect your Twitch account, open a category, then choose Following to see your live followed channels sorted by viewers.

Open source. Clear permissions.

The code is public under the MIT license. Inspect it on GitHub before you connect. It requests only Twitch access needed for Following, keeps credentials in browser-session memory, and has no analytics or publisher server. Open source makes the design inspectable; it is not a promise of zero risk.

Connect once per browser session

  1. Open Twitch Category Following from Chrome’s Extensions menu or its pinned toolbar icon.
  2. Choose Connect Twitch. Open the Twitch authorization page shown in setup and enter the displayed code if requested.
  3. Check the Twitch account and requested access, approve, then return to the setup tab. Keep that tab open until your connected login appears.
  4. Refresh your Twitch tab. Open a category’s Live Channels tab and choose Sort by → Following.

The extension uses the account you authorize, which can differ from the account signed in on the Twitch page. Regular releases include the application ID; you do not need to register a developer app.

For privacy, authorization stays in browser-session memory. Reconnect after restarting Chrome, reloading, updating or disabling the extension, or when authorization expires. It does not reconnect automatically.

Use Following

Choose Following again to refresh the live list. Supported language and tag filters apply to the loaded results. Choose any native sort to restore Twitch’s normal feed. This version supports the English Twitch interface and shows followed channels only.

If something goes wrong

No channels can mean none of your follows are live in that category. Check your filters and connected account. For connection errors, return to setup and reconnect; for network errors, retry when online. If Twitch’s layout changes, use a native sort and report the problem.

To disconnect, use Disconnect in setup. If offline, also revoke the app later in Twitch Connections. To remove it, open Chrome’s Extensions menu, choose Remove, then refresh Twitch.

Using a development build?

If setup asks for a public client ID, that build has no publisher application configured. Register your own Public application in the Twitch developer console, then paste its client ID. This build uses device authorization; it does not use an OAuth redirect callback. Never paste a client secret.

Get support

Report an issue on GitHub with your Chrome version, category, theme and steps. Do not include passwords, authorization codes or tokens. Read the privacy policy for data handling.
